## Odysseus-unique opportunities

Features competitors do not emphasize but Odysseus can offer:

- **Agent-assisted finance Q&A** — "Summarize my dining spend last quarter" via existing chat/agent
- **Email → transaction hints** — receipt emails linked to transactions (uses email module, phase 3)
- **Calendar bill reminders** — recurring bills on CalDAV (phase 3)
- **Unified backup** — finance in same `odysseus-backup` tarball as email and notes
- **No third-party aggregator** — manual import only; no Plaid tokens to manage
