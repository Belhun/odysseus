## Features

Inventory captured from the live Avalonia views/VMs and mirrored in the HTML exports.

### Projects hub (`ProjectsHubView` / `ProjectsHubViewModel`)

- Page title **Projects** and subtitle: active work, estimates needing acceptance, devices without projects.
- Search by device ID, phone, work order, or project # (`SearchQuery` / `SearchCommand`).
- **Include archived in search** checkbox (`IncludeArchivedInSearch`).
- **Refresh** (`RefreshCommand`).
- **Search results** list; visible only when results exist; rows open a project (`OpenProjectCommand(projectId)`).
- Three hub buckets:
  - **Active projects** — row shows device ID, status, client name (`ActiveProjects` / `ProjectHubRow`).
  - **Estimates not accepted** — rows open invoice (`EstimatesNotAccepted` / `EstimateHubRow` / `OpenInvoiceCommand`).
  - **Accepted — missing projects** — accepted invoices/devices still without a project (`AcceptedMissingProjects` / `MissingProjectHubRow`).
- Row models referenced: `ProjectHubRow`, `EstimateHubRow`, `MissingProjectHubRow`, `Project` (search).

### Project detail / workspace (`ProjectDetailView` / `ProjectDetailViewModel`)

- Header: title, device ID, project title, status `ComboBox`.
- Status options: `Intake`, `WaitingOnPartsPayment`, `WaitingForParts`, `WaitingOnDevice`, `ReadyToStart`, `InProgress`, `FinishedWaitingDropOff`, `WaitingOnPayment`.
- **Device** card: model, serial, color + **Save device fields**.
- **Notes** card: first contact, client issue, repair plan + **Save notes**.
- **Parts on this device** list (read-only in export).
- **Before / after photos**: upload buttons + file lists.
- **Screw map** (eligible when category is HW or Other; hidden for SW via `IsScrewMapEligible` / `ScrewMapService.IsCategoryEligible`):
  - No map yet (`ShowLibraryReuse`): start empty map, browse library, select library map, reuse selected (copy-on-write; source stays locked).
  - Map in progress (`HasScrewMap`): model label, upload screw-map photo, ordered photo layers with **Annotate**, optional provenance (“Reused from project …”).
  - Locked (`IsScrewMapLocked`): read-only warning; hide lock/upload; show **Publish to library** (title + comma-separated tags).
  - Published confirmation message when applicable.

### App shell context (not hub-owned)

- Sidebar nav samples: Dashboard, Invoice Calculator, Placeholder Merge, Diagnostics, Settings.
- Content header with back button and screen title (“Projects” / “Project”).

## UX

- Hub is a single scrollable column (~960px max in export) with search first, then three operational buckets.
- Active project rows are richer (device / status / client); estimate and missing-project rows are single-line labels.
- Empty states noted (e.g. “No active projects”) but sample data populated by default in the export.
- Project detail is a narrower card stack (~720px); Fluent/light styling approximated (`#f3f3f3` cards, Segoe UI, bordered buttons).
- Screw-map UX is state-heavy; export includes a temporary state switcher so designers can preview no-map / in-progress / locked / hidden-SW without backend data.
- Binding map comments in HTML are meant to keep redesigns mappable back to Avalonia properties/commands.
- Yellow “design export” callouts and the screw-state switcher are disposable for final mockups.
