## Issues/bugs

- **Root cause:** update flow deleted line items → `DeleteOrphanedPlaceholders` removed placeholder `Parts` still referenced in memory → INSERT `InvoiceItems` with stale `PartId` → FK failure (constraint 19 / extended 787). New-invoice create worked.
- Misleading toast mapped all error **19** to “already exists.”
- Edit save always prompted for a new date-based name instead of updating the same invoice.
- Edit save forced `Status=Estimate`, `IsFinalized=false` (would wipe finalized/sent state).

## UX

- Edit from dashboard → **Save Invoice** = silent update, same name/row.
- **Save as new Invoice** only when editing in calculator; always available on dedicated edit screen.
- Save-as-new: name dialog; calculator default `Client - today`; edit screen prefers `"<current> (copy)"`.
- After save-as-new: stay on the **new** invoice (`LoadWithInvoice` / `LoadInvoice`).
- Clear form exits edit mode.
