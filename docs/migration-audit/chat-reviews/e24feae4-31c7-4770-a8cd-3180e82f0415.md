## UX

- Client Dashboard should feel like a **workspace**: pick client → see work → preview without leaving → edit client in place.
- User memory of **cards** maps better to **invoice tiles + home Dashboard language** than to the Phase 9 DataGrid; Classic lands on **invoice cards + center preview**, not a spreadsheet.
- **MRU when search empty** is a strong daily-use preference (loved on Hub; kept as session MRU in overlay).
- Search should be a **thin bar**; results **hover over** content only while searching.
- Preview+ **Preview/Projects** tabs were liked visually but “don’t work for what I was hoping”; not carried into Classic.
- **Unified** client+invoice search rejected on look/feel.
- End decision: stop A/B on home; **one** Client Dashboard (Classic four-column); polish Notes on edit.
