## UX

**Bench-first philosophy (brainstorm):** protect the device; low friction mid-repair; ordered photos *are* the structure (not an iFixit clone). You pick fuzzy-lookup candidates; no auto-assign.

**Shipped interactions:**

- Project detail: Start map → upload ordered photos → **Annotate** per image  
- Annotation: **View** default (select/inspect); **Edit** for place/drag/delete  
- Placement: Edit on → double-click screw, right-click note  
- After click fix: blue banner when Edit is off (“Turn on Edit mode…”)  
- Lookup: enter mm dims → Find matches → tap result to navigate  
- Lock: read-only when locked; library publish when locked; browse/reuse before starting empty map  
- Provenance: reused photos show origin project device id under filename  

**Friction / ease gaps for Odyssey:**

- Desktop upload is the only capture path until S5  
- Edit mode off by default is easy to miss (banner helps; still a step)  
- Silent failures without toasts hurt trust  
- Library requires matching device model string and empty map  
- Right-click note is immediate add (not a context menu), which may surprise on web/touch
