### New ScrewMapView workspace (primary outcome)

- **`ScrewMapView.axaml` / `.axaml.cs`** + **`ScrewMapViewModel.cs`** — full-screen map workspace matching the wireframe:

# UX

Wireframe contract this chat enforced:

- Layout: **top strip → center canvas + right sidebar → bottom bar**
- Place next screw with **single click** on empty image area (not double-click like annotation)
- Selected screw → detail form; no selection → ordered global list `ORDER BY ScrewNumber`
- Thumbnail strip + Back/Next stay in sync via `CurrentImageIndex`
- Numbers **do not reset** when switching photos

Editing experience after autosave change:

- No Save button for details; trust debounce/interval + leave/switch flush
- Visible save status (`Unsaved` / `Saving` / `Saved`)
- Ctrl+Z undoes the whole detail form for the current screw session back to selection-time snapshot

Entry UX:

- Prefer **four-column project view** preview → `ScrewMapView`
- Annotation remains a fallback / older path from classic project detail
