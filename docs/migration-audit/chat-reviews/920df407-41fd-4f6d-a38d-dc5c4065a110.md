## Features

- **Client Dashboard → invoice edit:** `ClientDashboardViewModel.EditInvoice` → `NavigateToInvoiceCalculatorEditAsync` → `NavigationService.NavigateToInvoiceCalculatorEditAsync` loads `InvoiceCalculatorViewModel.LoadWithInvoice(invoiceId)` and shows `InvoiceCalculatorView`.
- **Invoice Calculator client picker:** search `TextBox` bound to `ClientSearchQuery`, results overlay driven by `ShowClientDropdown` / `ClientSearchResults` (not a native `ComboBox`). Includes an **"Add New"** row via `ClientSearchResult.CreateAddNew`.
- **Pre-fill paths:** `LoadWithInvoice` and `LoadWithClient` set `SelectedClient` then set `ClientSearchQuery` to the client's `DisplayName`.
- **Separate screen clarified:** `InvoiceEditView` / `InvoiceEditViewModel` are not the dashboard edit path for this flow; client combo behavior there was a red herring.
- **Code-behind focus:** `InvoiceCalculatorView.axaml.cs` `Loaded` / focus logic targets line-item price fields, not the client search control.
- **Fix shipped in SysForge:** early exit in `UpdateClientSearchResults` / `UpdateClientSearchResultsAsync` when `SelectedClient != null` and trimmed `ClientSearchQuery` equals `SelectedClient.DisplayName` (ordinal ignore-case); keeps `ShowClientDropdown = false`. Present today in `SysForge/ViewModels/InvoiceCalculatorViewModel.cs` around the async search helper.

## Issues/bugs

- **Bug:** Opening invoice edit from Client Dashboard with a client already selected (e.g. Alex) caused the client results panel to pop open even though the form was filled.
- **Root cause:** Any non-empty `ClientSearchQuery` ran `UpdateClientSearchResults()`, which always appended at least the **"Add New"** row, so `ShowClientDropdown` became true after programmatic fill of the display name.
- **Build friction (environment, not product):** full `dotnet build` on `SysForge.sln` failed while a running `SysForge.exe` locked `SysForge.dll` / `SysForge.exe` (PID noted as 6228); temp-output build and a later full solution build succeeded. Unrelated warning in `SysForge.Tests/DbTestFixture.cs` (nullable annotations).
