## UX

- Client Dashboard is the hub to **see invoices for a client** after calculator save; empty list with data in DB feels like “save failed.”
- Contact details need **labels**, not a stack of raw values.
- Search clear must **keep** the selected client.
- Keyboard: typeahead + **Down/Up/Enter** on both dashboard and calculator client pickers.
- After **Save Invoice**: name modal (prefilled), then land on that client’s dashboard with the named row visible.
- **Edit** = editable calculator with invoice loaded; **View** = unchangeable readable invoice (user request).
- **Diagnostics** as source of truth when UI and DB disagree.
- Running app must be closed before `dotnet build` / `dotnet run` or users test stale binaries.
