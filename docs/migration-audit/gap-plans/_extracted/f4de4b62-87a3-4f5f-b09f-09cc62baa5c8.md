  - Backup I/O outside the DB transaction; failure logs to Debug and does **not** abort save.
  - API exposed for future restore UI: `ListBackups`, `LoadBackup`, `InvoiceBackupSnapshot`.
  - Test: `SaveInvoice_OnUpdate_SnapshotsPriorStateToDiskBackup` (placeholder suite 11/11).

## UX

- **Client Dashboard** is the Phase 9 entry: find client → see invoices → Edit or Create.

- **Auto-backup**: invisible to user in this chat (no UI). Safety net is filesystem next to DB under `InvoiceBackups/`.
